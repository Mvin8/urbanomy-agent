# Проверки Urbanomy

Структура следует примеру blocksnet-agent: отдельные модули для MCP, A2A,
контрактов, выполнения заданий, данных и документации. Общие временные настройки
и синтетические кварталы — в `conftest.py`; подставные рабочие процессы — в `helpers.py`.

## Запуск

Из корня репозитория:

```bash
python -m pip install -e '.[dev]'
python -m pytest -q
```

Обычные тесты не требуют локальных GeoJSON/CatBoost-файлов, запущенного сервера,
Docker или ключей LLM. Геоданные создаются во временной директории; модель и LLM
подменены там, где проверяется вычислительный процесс. Статусы и отмена проверяются
на настоящих дочерних процессах. HTTP-тесты используют приложение внутри процесса.
Настройки окружения пользователя и `.env` изолированы фикстурой.

## Что проверяется

| Файл | Сценарии |
|---|---|
| `test_tool_contract.py` | Типы, границы, неизвестные поля, prompt/strategy, конфликтующие DataParts |
| `test_mcp_tool_exposure.py` | Каталог, обязательные аргументы, вызовы и сохранение заданий между HTTP-запросами |
| `test_a2a_card.py` | Адреса, навыки, версия и объявление Bearer без утечки токена |
| `test_a2a_tasks.py` | Завершение, polling, tenant, отмена, streaming и артефакты |
| `test_auth.py` | HTTP 401, публичная карточка и авторизованный вызов |
| `test_runtime.py` | Лимит параллельности, отмена, таймаут, сбой процесса, освобождение слота, shutdown |
| `test_data.py` | CRS, ID, выбор квартала, разрешённые наборы и явное исправление геометрий |
| `test_optimization.py` | Границы долей, итоговые ограничения, отказ без допустимых решений, LLM-оценка, логарифмическая цена |
| `test_settings.py` | Переопределение путей и лимитов через окружение |
| `test_tool_catalog_docs.py` | Совпадение документации с кодом и целостность локальных ссылок |
| `test_codesynapse_contract.py` | Внешняя строгая схема Agent Card, Task, Artifact и streaming updates |

Выборочные проверки:

```bash
python -m pytest tests/test_mcp_tool_exposure.py tests/test_a2a_tasks.py -q
python -m pytest tests/test_data.py tests/test_optimization.py -q
python -m pytest tests/test_runtime.py -q
```

## Контракт Codesynapse

Два теста внешнего контракта пропускаются, если `A2A_CONTRACTS_DIR` не задан.
Остальные проверки выполняются независимо. Схема не копируется в Urbanomy:
используется файл из той версии Codesynapse, к которой планируется подключение.
Если путь указан, но схема отсутствует, тест завершается ошибкой, а не пропускается.

```bash
A2A_CONTRACTS_DIR=/path/to/codesynapse-main/docs/contracts/a2a \
  python -m pytest tests/test_codesynapse_contract.py -q
```

Ожидаемый файл: `synapse-a2a-1.0.schema.json`.

## Проверка документации

```bash
python scripts/generate_docs.py
python scripts/generate_docs.py --check
```

Первая команда обновляет каталог MCP и Agent Card. Вторая только сравнивает файлы
с текущим кодом и возвращает ненулевой код при расхождении. Тесты документации
ничего не перезаписывают, поэтому устаревший каталог не сможет исправить себя
во время проверки и скрыть ошибку.

## Сквозной запуск с реальными данными

После [запуска сервера](../RUN.md):

```bash
python scripts/smoke_server.py
python scripts/smoke_server.py --compute
```

Без `--compute` проверяются HTTP, каталог MCP и отказ A2A на неверный запрос.
С `--compute` выполняются оценка земли через MCP и короткая NSGA-II-оптимизация
через A2A на настоящем наборе `baseline` для квартала 86. LLM отключён.
Другие данные задаются через `--dataset` и `--target`; адрес — через `--url`.
Для защищённого HTTP передайте `URBANOMY_API_TOKEN` через окружение.

Live LLM и Docker-сборка не входят в обычный pytest. Тестовый оценщик подтверждает
прохождение стратегии и использование оценки; он не измеряет качество реальной LLM.
