# Проверки

Из корня проекта после установки `.[dev]`:

```bash
python -m pytest -q
```

Тесты проверяют MCP/A2A, схемы запросов, доступ к данным, ограничения оптимизации,
статусы, отмену, таймауты и документацию. Используют временные данные и подставные
модель/LLM. Ключи и работающий сервер не нужны.

Два теста внешнего контракта требуют `A2A_CONTRACTS_DIR` с файлом
`synapse-a2a-1.0.schema.json`. Без этой настройки они пропускаются.

Проверка на настоящих данных при запущенном сервере:

```bash
python scripts/smoke_server.py --compute
```

Оценка через MCP и короткая оптимизация через A2A, сценарий `baseline`, квартал `86`.
LLM отключена. Опции: `--url`, `--scenario`, `--target`. При авторизации передайте
`URBANOMY_API_TOKEN` через окружение: скрипт `.env` не загружает.
Без `--compute` проверяются только подключение и обработка запроса.

Документация: `python scripts/generate_docs.py --check`.
Реальный LLM-провайдер и Docker-сборка в обычные тесты не входят.
