# Документация Urbanomy

Два интерфейса над общими расчётами: **9 MCP-инструментов** и **2 A2A-навыка**.
Документы описывают текущую реализацию, включая её ограничения.

| Документ | Назначение |
|---|---|
| [Быстрый запуск](../RUN.md) | Запустить сервис и проверить подключение |
| [Архитектура](architecture.md) | Компоненты, поток расчёта и жизненный цикл задания |
| [Контракт инструментов](tool_contract.md) | Данные, выбор квартала, constraints, strategy/prompt, ответы и ошибки |
| [Развёртывание](deployment.md) | Установка, настройки, Docker и таймауты |
| [Каталог MCP](mcp_tool_catalog.md) | Описания и JSON Schema всех инструментов из живого кода |
| [Карточка A2A](a2a_agent_card.md) | Реальная Agent Card для локального примера |
| [Карта кода](WIKI-LLM.md) | Где искать реализацию и соответствующие тесты |
| [Тесты](../tests/README.md) | Автоматические проверки и внешний контракт Codesynapse |

Каталог MCP и карточка A2A обновляются командой
`python scripts/generate_docs.py`. Тесты проверяют их соответствие коду,
не перезаписывая документацию. Остальные документы редактируются вручную.

Организация документации и тестов следует примеру
[blocksnet-agent](https://github.com/Eynor-K/blocksnet-agent/tree/37dcf87b68cfeec7a280a70f94ead3d4baac70a8).
Функциональность и ограничения описаны для Urbanomy; дополнительные возможности
BlocksNet, которых здесь нет, в контракт не включены.
