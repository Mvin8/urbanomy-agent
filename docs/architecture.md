# Архитектура

```text
MCP / A2A → UrbanomyService → ScenarioRegistry → JobManager
                                                 ↓
                                      отдельный рабочий процесс
                                                 ↓
                              CatBoost / NSGA-II + опциональная LLM
                                                 ↓
                                      JSON, сводка, GeoJSON
```

- Оба транспорта используют общие схемы запросов и вычислительное ядро.
- `ScenarioRegistry` читает только подготовленные папки внутри `DATA_DIR`.
- `JobManager` ограничивает параллелизм, контролирует таймаут и отменяет процессы.
- CatBoost оценивает кварталы с учётом окружения. NSGA-II меняет параметры выбранного
  квартала; ограничения проверяются до оценки LLM.
- Результаты записываются на диск, состояние заданий хранится в памяти.
  База данных, очередь и восстановление после перезапуска не предусмотрены.
